## 五、站立的判定方式（核心机制）

站立与行走**不再使用手写矩形列表**，而是查一张预烘焙的高度图：

- 脚本：`bake/bake.ts`，命令 `npm run bake`
- 网格：188 × 146 格，1 米一格，每格打 **3×3 共 9 条**向下射线取最高命中点
- 输出：`public/terrain.json`（约 89 KB），未命中记为 −1（海）
- 运行时：`src/pixel_harbor/harbor_heightmap.ts` 提供 `isLandAt(x,z)` 与 `terrainHeightAt(x,z)`
- `canWalkAt` 与 `findSupportHeight` 优先查高度图，加载失败时退回旧的矩形判定

因此：**往场景里加任何模型，重新 bake 一次就自动能站能走。**

相关细节：

- 树干障碍带 2.2 米高度，站在树冠上不会被挡
- 森林里有 `TREE_EXCLUSIONS` 清单，可按坐标点名剔除单棵树

## 八、输入与相机

- 移动：WASD / 触屏摇杆，跳跃，坡道按地面高度行走
- 飞行：按 `F` 起降，可在屋顶、树冠、灯塔平台降落；落水转游泳
- 游泳：贴水面移动，游到岸边自动上岸
- 视角：`V` 切第一 / 第三人称
- 鼠标锁定：
  - **右键**：两种视角都能锁定 / 解锁
  - **左键**：第一人称锁定；第三人称保持拖动
  - 钓鱼、面板打开、望远镜打开时不锁定
- 钓鱼时相机可自由旋转
