# Little Prince's Secret Base

在项目目录运行 `npm install` 和 `npm run dev`，打开终端列出的地址。首页先显示入口；点击「进入渔港」才加载 Three.js 并启动声音。「了解我」打开无需 WebGL 的普通阅读。3D 漫游需要 WebGL 2。用 `npm run build` 检查 TypeScript 并构建站点。

## 漫游

- 桌面端用 WASD 或方向键朝镜头所指方向移动，按住 Shift 加速，按空格单次跳跃。横向拖动绕人物旋转，纵向拖动改变俯仰，滚轮调整距离。
- 手机端拖动左下角摇杆移动，使用右侧「跳跃」按钮，单指滑动画面环视。首次进入会显示操作指南，关闭后可从「菜单 → 帮助」重新打开。
- 从起点沿栈桥往前，到船边打开「查看作品集」。往回走到西岸，可找到「展览公告栏」。进入互动范围时会出现地面圆环和操作提示。
- 多数地点面板打开时可用 WASD 或触屏摇杆继续走动，离开当前地点的范围会自动收起。渔获和许愿面板打开时暂停移动。焦点在面板内时，方向键可用于滚动。Esc 和关闭按钮也可收起面板。
- 按 M 或在右上「菜单」中选「地图」。地图首次打开时烘焙并缓存；点菱形标记查看简介，选择「传送到这里」或「给我指路」。指路箭头随镜头转向，到达目标范围后消失，也可手动取消。地图支持拖动、双指缩放和复原。
- 「菜单 → 帮助 → 重置视角」平滑回到人物背后和默认俯角。「我卡住了」会将人物送到最近的安全点，在灯塔和游船上分别回到塔门及南湾码头。
- 系统启用「减少动态效果」时，环境动画、标签浮动、灯塔旋转、落地回弹和面板动效会停用。

人物外观、移动响应和跳跃参数集中在 `src/pixel_harbor/harbor_movement_config.ts`。响应时间以秒为单位，表示达到目标变化量 90% 所需的时间。只有配置中指定的岸上木箱、木桶可越过，面板打开时和船上无法起跳。

面板淡入淡出时长和互动提示最小字号在 `src/pixel_harbor/harbor_interaction_config.ts`。地点标签、图标和传送设置在 `src/pixel_harbor/harbor_places_config.ts`。

## 斗篷飞行

- 按 F 起飞或请求降落。飞行时用 WASD 平移、空格上升、Ctrl 或 C 下降、Shift 加速。触屏用摇杆和飞行、上升、下降、加速按钮。
- 飞行可以跨过海面。若下方是海水、冰面或被物体占用，先飞到空旷岸边再降落。靠近活动边缘会减速并进入较浓的雾。可在「菜单 → 设置」关闭飞行。
- 速度、高度、范围、斗篷和姿态参数集中在 `src/harbor_flight/harbor-flight-config.ts`。低画质下斗篷保留四段。飞行音效走环境与音效音量，缺少 `cape.mp3` 或 `wind.mp3` 时使用滤波噪声。

## 灯塔、后村与南湾导览

- 「菜单 → 设置」可切换清晨或夜晚；按 T 循环晴、雨、雪，按 V 切换第一与第三人称。过渡默认 2 秒，浏览器保存选择。清晨为默认状态。夜景使用像素光晕和自发光材质，新增动态点光源为零。颜色、光强、光束和低帧率阈值在 `src/pixel_harbor/harbor_lighting_config.ts`。
- 持续低帧率时分档减少雨雪粒子、地面效果、远景细节、村民和动物，再关闭光束、树影和尾迹等效果。手机默认低画质，可在入口或菜单中修改。
- 从灯塔门口登塔，在平台步行、环视或点击地标聚焦。再次点击该地标或「返回全景」解除聚焦。按 E、Esc 或点「下塔」返回。平台的望远镜可用滚轮或按钮调整倍率，Esc 退出。
- 从南湾石墙的木坡道进入后村林径。沿村长小屋后方的后山林径上坡，山顶长椅可触发约 25 秒的黄昏过渡，用任意按键、点击或「结束观景」退出，恢复原有日夜设置。
- 到南湾码头找船夫，选择「乘船游览」自动经过三个观景点后回到码头。可随时点击「回到码头」或按 Esc。也可以选「自己开船」：W/S 推进和倒车，A/D 让船头分别向左和向右，倒车也一样。触屏摇杆采用相同方向。Shift 加速，靠近泊位可按 E 靠岸。选择「介绍一下这里」后，可用「带我去」抵达相应地点。访问记录保存在当前浏览器中。
- 倒车转向由 `src/pixel_harbor/harbor_sailing_config.ts` 的 `invertSteerWhenReversing` 控制。默认为 `false`，倒车时保留船头优先。
- 靠近猫狗，会出现名字和「摸摸」提示。名字、毛色、活动范围在 `src/pixel_harbor/harbor_animals_config.ts`，船夫对话、导览线路及停靠点讲解在 `src/pixel_harbor/harbor_captain_config.ts`，瞭望、黄昏和后村配置在 `src/pixel_harbor/harbor_exploration_config.ts`。

## 钓鱼和许愿

- 从地图选「钓鱼点」可抵达栈桥泊位的船尾侧（A1）。按 E 或点提示抛竿，等待 3–10 秒；浮漂下沉时，在 1.5 秒内按 E 或点「收竿」。错过后可以再抛一竿。Esc 或「结束钓鱼」收竿退出。钓鱼期间不能移动、跳跃或飞行，第一人称和触屏可用。旁边的泊位仍可正常靠船，下雪时落漂水面保持开放。
- 「渔获记录」按种类记录本浏览器钓到过的鱼和物件。瓶中信可从渔获卡打开，正文待填写。
- 「许愿台」在灯塔门前向海的空地（B2）。按 E 或点提示打开，最多输入 30 字，提交后纸灯升空，灯塔光束短暂增强。靠近石台可点最近的纸灯，或在「我的愿望」查看、逐条删除、清空；最多保留 20 条。愿望只保存在当前浏览器，不上传。
- 地点、计时、渔获介绍、夜雨雪权重、瓶中信、可选愿望示例和纸灯上限都在 `src/harbor_pastimes/harbor-pastimes-config.ts`。低画质最多显示 2 盏留存纸灯和 1 盏飞行纸灯；减少动态效果时纸灯静态显示后消失。
- 可选音效文件为 `fish_cast.mp3`、`fish_splash.mp3`、`fish_bite.mp3`、`fish_reel.mp3`、`wish_chime.mp3`，放入 `public/assets/audio/sfx/`。没有文件时使用程序合成音。

## 音乐、天气和替换素材

- 声音在点击「进入渔港」后启动。「菜单 → 设置」可调整四路音量和静音。曲目默认「随场景自动」，主动选定某首后才会显示并保存该固定偏好。「关于」读取供稿署名。落日互动保留当前曲目，并暂时柔化音乐。
- 音频放在 `public/assets/audio/music/` 和 `public/assets/audio/sfx/`；槽位、曲目映射、音量和 10 MiB 总预算在 `src/harbor_shell/harbor-audio-config.ts`。独立协议正文补放为 `public/assets/audio/music/LICENSE_CC0.txt`。海鸥、猫和狗缺少录音时静默，其余有程序化替代。
- 入口使用 2D 像素展台。按钮文案、站名开关和角色图路径集中在 `src/site-config.ts` 的 `config.entry`。左侧或下方的标签进入渔港和阅读页。点展台旁的喇叭可静音，悬停、长按或键盘聚焦可调总音量。入口和场景设置共用保存的音量。
- 角色图在 `public/assets/entry/hero.png`，可选的独立围巾层为 `hero-scarf.png`，两层画布尺寸应相同。缺少角色图时显示剪影。仅供美术参考的原图放项目根部 `assets/reference/character_ref.png`，不要放进 `public`。
- 新增或移除可选素材后，重启 Vite 或重新构建以刷新本地素材清单。音频和素材地址以 Vite 的部署 base 为准。
- 雨天角色自动撑伞；雪天先积雪再结冰。码头航道和导览路线留有通行水域。天气时长、粒子和冰面遮罩在 `src/harbor_expansion/harbor-weather-config.ts`。

本批改动和实测数据见 [维护记录](docs/harbor_second_batch.md)。

## 普通阅读

在入口选「了解我」，走到村长小屋并互动，或在「菜单 → 关于」点「了解我」，都会打开同一普通阅读页（`/?mode=read`）。页面含个人简介、项目、联系方式、简历按钮和地点目录。进入后卸载 3D 场景。站点界面与浏览器标签页的站名读取 `src/site-config.ts` 的 `config.siteTitle`。

## 更新作品、简历和联系方式

把图片放进 `public/artwork/harbor/`，在 `src/pixel_harbor/harbor_art_catalog.ts` 的 `ARTWORKS` 中修改作品资料和 `image` 路径，例如 `/artwork/harbor/my-work.png`。作品船、展架和阅读模式共用作品数据。保留原有 `id` 可沿用已有展位。展架的位置和朝向在 `src/pixel_harbor/harbor_exhibits.ts` 的 `SITES` 中设置。

在 `src/pixel_harbor/harbor_profile.ts` 中填写姓名、岗位、简介、头像、技能、邮箱、链接和项目。「了解我」页面读取这些资料。可将 PDF 放到 `public/resume.pdf` 并设置 `resumePdf: '/resume.pdf'`，文件缺失时阅读页会禁用下载。项目的 `jumpTo` 填已有地点 ID，例如 `portfolio` 或 `eval`。开发模式右下角的「待填写资料」列出空字段。

## 评测站

从栈桥回到西岸，再沿岸往南，在渔具仓库旁可找到「评测站」。普通阅读模式可从地点目录直接跳到评测站。

- 在 `src/pixel_harbor/eval_station_config.ts` 更新介绍、三张卡片的缩略图、来源标签和链接。来源手动填写「实战复现」或「方案演示」。
- `methods` 填写公开报告或方法说明链接。填入 `workbenchUrl` 后显示工作台入口。
- 把公开演示的 MP4 和封面放进 `public/assets/eval_station/`，填写 `video.src` 和 `video.poster`，例如 `/assets/eval_station/demo.mp4`。录屏点击后才加载，默认上限为 25 MiB。
- 只放自建演示和可公开分享的素材。
